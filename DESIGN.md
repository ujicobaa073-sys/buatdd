# DESIGN.md: Bucin Web untuk DD

## Identity
Halaman personal tribute buat satu orang (DD). Bukan produk, bukan landing page bisnis. Tone: jujur, bucin, sedikit malu, lembut. Web ini hadir karena ada satu orang yang mau dilihat feed-nya setiap hari.

## Personality
Lembut, romantis, tidak berisik. "Bucin" tapi tidak cringe. Lebih dekat ke surat tulisan tangan daripada iklan.

## Palette
- Base: pink pastel dreamy (#fdf2f4, #fce7f3, #fbcfe8)
- Core: deep pink (#ec4899) sebagai accent tunggal
- Text: deep purple (#4a044e, #701a75) untuk kontras WCAG AA
- Neutral: white solid untuk surface
- Tidak ada gradient biru-ungu, neon, atau rainbow

## Typography
- Body: Poppins (readability, karakter modern lembut)
- Display: Great Vibes (hanya untuk nama DD, sebagai identity motif)
- Tidak pakai monospace atau uppercase wide-tracking

## Mood
Tenang romantis. Energy 2, Rhythm 2, Motion 2. Bukan awwwards dramatis, bukan sterile flat.

## Dials
ENERGY 2 / RHYTHM 2 / MOTION 2

## Identity motif
Partikel hati terapung di canvas. Satu motif berulang yang membuat web ini punya karakter sendiri.

## Aset
- Teks surat & judul: template, user edit sendiri di config.js (R-23: tidak mengarang teks seolah kata user)
- Musik: file lokal user (Perahu Kertas - Maudy Ayunda)
- IG embed: URL post publik yang user kasih
